## Review process

- Open your pull request as normal, following [`CONTRIBUTING.md`](CONTRIBUTING.md). Every commit
  must carry a `Signed-off-by:` line certifying the [`DCO`](DCO) (`git commit -s`).
- Known defects and proposals are tracked in [`docs/issues/`](docs/issues/README.md); reference
  the page you are fixing in the pull request description.
- If a maintainer has not picked up the pull request within a few business days, ping
  **opensource@craton.com.ar** with the link.
- Security reports follow a different path: see [`SECURITY.md`](SECURITY.md).

## Releases

Releases are cut by a maintainer following [`RELEASING.md`](RELEASING.md).

## Becoming a maintainer

Maintainership is granted by existing maintainers based on sustained, high-quality
contributions. There is no formal application process: keep contributing, and we will reach out.
